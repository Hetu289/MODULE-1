List and explain at least three Bootstrap components.
1. Navbar

A navigation bar used at the top of websites.
It includes menus, brand logos, togglers, and can collapse on mobile screens automatically.
 
2. Cards

A card is a small, boxed component that can contain an image, title, text, and button.
Useful for showing portfolio items, products, profiles, etc.

3. Buttons

Bootstrap provides different button styles using classes like:

btn-primary

btn-success

btn-danger

These buttons are already styled and look modern without writing extra CSS.
