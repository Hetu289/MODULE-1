Explain the Bootstrap grid system and how it helps create responsive layouts.
The Bootstrap grid system is a layout system based on 12 equal columns.
You can divide the screen into these columns to arrange content.

How it works:

Grid system uses:

Container → main wrapper

Row → horizontal grouping

Columns (col-) → actual content area

Why is it responsive?

Bootstrap has built-in screen size breakpoints:

col- → extra small screens (phones)

col-sm- → small screens

col-md- → tablets

col-lg- → laptops

col-xl- → large desktops

Example:
col-md-6 means → on medium screens, the block will take 6 out of 12 columns.

The grid automatically changes the layout based on screen size, making the website fully responsive.
