What is Bootstrap, and why is it useful for website design?

Bootstrap is a popular front-end framework that provides pre-built CSS and JavaScript components for rapid web development.

It's useful for website design because it:

Speeds up development - Ready-made components reduce coding time
Ensures responsiveness - Built-in grid system works seamlessly across devices
Maintains consistency - Standardized styling and components across the site
Provides cross-browser compatibility - Works reliably across modern browsers
Includes utilities - Buttons, forms, navigation, cards, and more out-of-the-box
Simplifies customization - Easily themeable with variables and mixins
