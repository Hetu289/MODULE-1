Describe the purpose of utility classes in Bootstrap and give examples.

Utility classes are small, quick CSS classes used to modify spacing, alignment, colors, display, and size without writing custom CSS.

Examples of utility classes:

Spacing: mt-3, mb-4, p-2

Text colors: text-danger, text-primary

Background colors: bg-dark, bg-warning

Display: d-flex, d-block, d-none

Text alignment: text-center, text-end

These classes help speed up development and keep code clean.
