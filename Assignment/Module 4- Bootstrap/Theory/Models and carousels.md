Explain how modals and carousels work in Bootstrap.

Modal

A modal is a popup window that appears on top of the webpage.

It is used for login forms, contact forms, confirmation messages, etc.

Modals open using data-bs-toggle="modal" and close automatically when clicking outside or pressing the close button.

Bootstrap handles the animation and background dimming automatically.

Carousel

A carousel is an image slider that moves images automatically or by clicking next/previous arrows.

Each slide is called a carousel-item.

Carousels are useful for hero banners, product images, or galleries.

Bootstrap provides built-in JavaScript to handle transitions smoothly.
